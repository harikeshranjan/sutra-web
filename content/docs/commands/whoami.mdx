# whoami Command

The `sutra whoami` command is a simple yet powerful tool that allows you to display the currently authenticated user. This can be useful for verifying your identity and ensuring that you are working with the correct user account.

When you run `sutra whoami`, it will display the username and email address associated with your current authentication token.

```bash
sutra whoami
```

## Benefits

Using `sutra whoami` can help you quickly verify your identity and ensure that you are working with the correct user account. This can be especially useful in collaborative environments where multiple users may be working on the same codebase.
