# Installation

To install Sutra, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Harikesh-14/Sutra.git
   cd Sutra
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
