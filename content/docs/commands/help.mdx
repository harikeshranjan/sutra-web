# Help Command

The `sutra --help` command is an essential tool for anyone using the Sutra CLI. It provides detailed information about all available commands, including their usage, options, and examples. This can be incredibly helpful for both new and experienced users who want to quickly understand how to use the CLI effectively.

When you run `sutra --help`, it will display a list of all available commands along with a brief description of each command. You can also get more detailed information about a specific command by running `sutra --help <command>`.

```bash
sutra --help
```

## Benefits

Using `sutra --help` can save you time and effort by providing quick access to important information about the CLI. Instead of searching through documentation or online resources, you can simply use the help command to find the information you need. This can be especially useful when you're working on a complex task and need to quickly reference the available commands and their options.
